# PriceIntel v1.0 — швидке встановлення для другого акаунта

**Made by Пума (Чернявський А.)**

1. Створи окремий GitHub-репозиторій і завантаж туди весь вміст папки `priceintel_web_v1.0.0`.
2. У Render створи новий Web Service з цього репозиторію.
3. Додай Environment Variable `SERPER_API_KEY` зі своїм окремим ключем Serper.
4. Не додавай API-ключ у GitHub, `config.json` або чат.
5. Дочекайся `Deploy succeeded`.
6. Відкрий сайт, завантаж тестовий CSV на 20–30 товарів.
7. Перевір URL виду `/jobs/<id>`.
8. У Render Application Logs перевір `ENGINE v1.0`, `PREFETCH`, `CHECKPOINT SAVED`, `RELEASE METRICS`.
9. Натисни F5 під час аналізу — job не повинен початися з нуля.
10. Зупини тестовий job і перевір `Продовжити з checkpoint`.

## Не робити
- не змішувати файли різних версій;
- не залишати старий `runner.py`;
- не запускати одразу десятки тисяч товарів до контрольного тесту;
- не використовувати один SERPER_API_KEY на кількох незалежних власників без потреби.
