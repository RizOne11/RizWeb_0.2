# PUMA Platform v1.1 — Foundation Release

## Що це
Одна web-платформа з двома окремими модулями:

- **доПУМАгатель** — ринковий аналіз на базі перевіреного ядра PriceIntel v1.0.
- **ПереводоПУМОгатель** — контент-модуль для майбутнього AI-перекладу, редагування та експорту в OpenCart 4.1.

## Що вже працює у v1.1 Foundation

- спільний стартовий екран PUMA Platform;
- доПУМАгатель приймає **YML / XML / CSV**;
- YML нормалізується у той самий набір полів, який очікує ядро аналізу;
- `vendorCode` YML переноситься в `Артикул` без змін;
- **SKU Lock**: артикул постачальника не перекладається й не нормалізується;
- у звіт додано `Стара ціна` та `Знижка, %` перед `Твоя ціна`;
- знижка показується тільки коли стара ціна реально більша за поточну;
- ПереводоПУМОгатель читає YML/CSV та показує картку товару: оригінальна назва, артикул, бренд, категорія, ціни, опис, характеристики;
- українська версія вже відокремлена від оригіналу архітектурно, але AI-виклик ще не підключений;
- ядро market search / matching / adaptive search / checkpoint-resume не переписувалось.

## Потік

`YML/CSV -> PUMA Platform -> доПУМАгатель -> ПереводоПУМОгатель -> OpenCart 4.1 -> Google Merchant`

## Наступний етап

1. Постійна база нормалізованих товарів та статусів контенту.
2. Підключення OpenAI API до ПереводоПУМОгателя.
3. Окремі поля UA: назва, опис, характеристики, SEO title/meta description.
4. Масова обробка вибраних товарів.
5. Експортер під конкретний імпортер OpenCart 4.1.
6. Merchant feed із уже опублікованого українського каталогу.

## Безпека артикулу

Артикул постачальника (`vendorCode`) є immutable business key. У майбутніх AI-запитах він передаватиметься як захищене поле і результат AI не матиме права його перезаписувати.
